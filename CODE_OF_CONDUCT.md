# Code of Conduct

## Our standard

Participation in this project's spaces — issues, pull requests, discussions,
and security reports — is expected to be professional, respectful, and honest.

Expected:

- Assume good faith; disagree with ideas, not people.
- Keep criticism specific and technical. "This breaks forward secrecy when X"
  is useful; insults are not.
- Respect maintainers' and contributors' time. Clear reports, minimal
  reproductions, and honest uncertainty ("I have not verified this") all help.
- Respect the security process: never disclose suspected vulnerabilities in
  public threads.

Unacceptable:

- Harassment, personal attacks, or discriminatory language of any kind.
- Sustained disruption, bad-faith trolling, or sealioning.
- Publishing others' private information.
- Misrepresenting the project's security properties — in either direction —
  after being corrected with evidence.

## Enforcement

Report conduct problems to conduct@open-e2ee.dev. Maintainers may edit, hide,
or delete comments and may block contributors for violations, escalating from
warning to permanent ban based on severity and repetition. Reports are handled
confidentially.

## Scope

This code applies in all project spaces and when representing the project in
public. It is adapted in spirit from the
[Contributor Covenant](https://www.contributor-covenant.org/), simplified for
a small project.
